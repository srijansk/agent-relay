## Summary
The Python CLI tool `myapp` incorrectly interprets the feature flag `feature_flags.enable_new_router` when set to the quoted string `"false"` in `config.yaml` as `True`, causing the new router to be enabled. The expected behavior is for the application to interpret `"false"` as `False`, thus keeping the legacy router enabled.

## Steps to reproduce
1. Create a new directory for the reproduction:
   ```bash
   mkdir myapp-repro && cd myapp-repro
   ```

2. Create a virtual environment and activate it:
   ```bash
   python3 -m venv venv
   source venv/bin/activate
   ```

3. Install PyYAML (assuming `myapp` uses it for YAML parsing):
   ```bash
   pip install pyyaml
   ```

4. Create the following directory structure and files:
   ```bash
   mkdir -p src/myapp
   touch src/myapp/config.py src/myapp/router.py config.yaml
   ```

5. Add the following content to `src/myapp/config.py`:
   ```python
   import yaml

   def load_config():
       with open('config.yaml', 'r') as file:
           return yaml.safe_load(file)
   ```

6. Add the following content to `src/myapp/router.py`:
   ```python
   from src.myapp.config import load_config

   def use_new_router():
       print("Using new router")

   def use_legacy_router():
       print("Using legacy router")

   def main():
       config = load_config()
       if config['feature_flags']['enable_new_router']:
           use_new_router()
       else:
           use_legacy_router()

   if __name__ == "__main__":
       main()
   ```

7. Add the following content to `config.yaml`:
   ```yaml
   feature_flags:
     enable_new_router: "false"
   ```

8. Run the application:
   ```bash
   python src/myapp/router.py
   ```

## Environment
- Python 3.x (tested with Python 3.8)
- PyYAML version 6.0
- Operating System: Ubuntu 20.04 LTS

## Evidence
Upon running the application, the output is:
```
Using new router
```
This output is generated by the `use_new_router()` function in `src/myapp/router.py`, indicating that the application incorrectly interprets the quoted string `"false"` as `True`. The expected output should be:
```
Using legacy router
```
This would indicate that the application correctly interprets `"false"` as `False`, thus using the legacy router.
